Projet

Analyse des best-sellers Amazon France 2020-2026

Analyse exploratoire de 689 livres issus du Top 100 Amazon France afin d’identifier les catégories dominantes, les tendances d’évolution et les caractéristiques communes aux livres les mieux classés.

Ce projet combine nettoyage de données, harmonisation des catégories, analyse exploratoire, visualisation et création d’un dashboard interactif avec Looker Studio.

Résultats clés

  • Les romans deviennent la catégorie dominante à partir de 2023.
  • Les BD/Manga obtiennent les meilleures notes moyennes.
  • La Science-fiction/Fantasy génère le plus d’avis moyens par livre.
  • La note moyenne seule explique très peu le classement dans le Top 100.

Outils : Python, Pandas, Matplotlib, Excel/CSV, Looker Studio, GitHub
